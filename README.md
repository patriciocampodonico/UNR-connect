# UNR Connect

Prototipo interactivo de **UNR Connect**, una propuesta de movilidad nocturna para estudiantes de la Universidad Nacional de Rosario.

## Cómo abrirlo

- **Desde el celular o la compu:** https://patriciocampodonico.github.io/UNR-connect/
- **Sin internet:** descargá `index.html` y abrilo con doble clic.

Está pensado para verse en un celular. En la pantalla de acceso se puede ingresar sin completar los campos.

## Qué incluye

1. Acceso con SIU Guaraní
2. Configuración inicial (polo, facultad, líneas y parada)
3. Inicio con el tiempo de llegada del colectivo
4. Punto de encuentro (salida grupal y tótem de cada facultad)
5. Transbordos seguros
6. Viaje compartido
7. Perfil

## Aclaración

Es un prototipo académico. Los nombres, horarios, costos, grupos y datos de seguridad son de demostración: no están conectados a ningún sistema real.

El mapa de Transbordos usa las calles reales de Rosario y los tiempos de caminata se calcularon sobre ellas. Datos del mapa: © OpenStreetMap contributors, bajo licencia ODbL (https://www.openstreetmap.org/copyright).
